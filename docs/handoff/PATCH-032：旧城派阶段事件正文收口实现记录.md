# Patch 032：旧城派阶段事件正文收口实现记录

## 1. 完成范围

本 Patch 只接入用户本轮明确确认的 4 段玩家可见旧城派阶段事件正文：

- `old_city.event.southern_letter.body`；
- `old_city.event.hidden_rumors.body`；
- `old_city.event.public_gathering.body`；
- `old_city.event.exodus_countdown.body`。

四段正文进入正式 `TextRegistry`，状态为 `FINAL`。既有文案资产中已经封存的四个事件标题与对应选项文字也进入同一注册表；`old_city_view` 在阶段活动时返回标题、正文、正文状态、选项文字和原有结构化预览，阶段未活动时返回稳定的空文本形状。

本 Patch 不修改旧城派第 24 天触发、阶段阈值、增长、阶段推进、选项可用条件、选项效果、承诺、出走、人口、资源、信任、恐慌、随机性或任何平衡值；不开始 Patch 033。

## 2. 用户确认正文（逐字核验依据）

### `old_city.event.southern_letter.body`

> 今天，一封从南方辗转送来的信进了炉城。
> 信里的消息并不完整，却提到更远的地方或许仍有人活着，也许还有能够落脚的去处。
> 没人知道这封信经过了多久，也没人能确认里面的话还剩几分真实。
> 可只要“城外也许还有路”这句话被人看见，
> 炉城就已经不再是唯一的答案。

### `old_city.event.hidden_rumors.body`

> 最近，关于离开炉城的消息开始在私下流传。
> 有人说南边还有聚居地，有人说旧路并没有完全断掉，也有人只是反复问同一句话：
> 这里真的是最后一个还能活下去的地方吗？
> 这些话还没有被公开喊出来。
> 它们只是出现在排队、换班和熄灯以后，
> 越来越多人听见，也越来越少人愿意承认自己听见过。

### `old_city.event.public_gathering.body`

> 原本藏在低声交谈里的怀疑，今天第一次聚到了明面上。
> 越来越多人停在公共区域，没有散去。
> 他们谈论城外的去处，谈论炉城还能撑多久，也要求得到一个足以让人继续留下的答案。
> 这还不是一场出走。
> 但已经不再只是传言。
> 当怀疑开始站在人群中央，
> 执政官就不能再假装它只存在于角落里。

### `old_city.event.exodus_countdown.body`

> 旧城派的人数还在上升。
> 如今，已经有人开始整理能够带走的东西，询问城门、路线和外面的天气。
> 他们还没有真正离开。
> 可“要不要走”正在变成“什么时候走”。
> 炉城仍有时间。
> 只是已经没人能再把这件事当成一句随时会散掉的抱怨。
> 当有人开始为离开做准备时，
> 留下本身，也开始需要一个理由。

## 3. 既有封存文字接线

以下标题与选项不是本 Patch 新创作，来源仍为第 5 轮文案资产：

- 南方来信：公布来信 / 压下来信；
- 暗中传言：公开解释 / 暂不处理；
- 公开集结：公开说明 / 加强巡查 / 暂不处理；
- 离城倒计时：承诺压低旧城派人数 / 暂不阻拦 / 争取最后时间。

内部机制 ID `southern_letter`、`rumors`、`public_gathering`、`countdown` 及各选项内部 ID 保持不变。
