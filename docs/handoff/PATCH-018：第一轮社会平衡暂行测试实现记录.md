# Patch 018：第一轮社会平衡暂行测试实现记录

## 来源与性质

本补丁依据第四至第七次盲玩报告、每日信任/恐慌记录、关键日存档与完整回放施工。用户明确确认本轮数值只用于下一轮对照试玩，不定为最终封存值。

本轮所有调整继续使用既有 `TEST_NUMERIC` 配置身份。没有将暂行结果回写成旧资料原有封存数值，也没有覆盖路线的正式机制边界。

## 盲玩结论

- 火盆集会在炉心与供暖正常时每日恐慌 -1，曾在偏难地图铁腕局中从 D4 起连续把恐慌压至 0；这使后续铁腕恐慌压制大量溢出，信任代价却完整支付。
- 两次誓言完整局分别以 20 分和 24 分高胜结束，终局信任/恐慌为 91/0 与 85/0。誓言前五条炉律原本无条件合计提供信任 +5，守炉宣誓和共食誓餐还能反复恢复社会指标。
- 一次铁腕偏难局在 D54 因信任归零失败，不能据此认定铁腕过强；本轮不修改铁腕路线。
- 医疗配给已经由 Patch 013 调整为每人 5 熟食、最多 10 人、冷却 5 天；第二研究所、资源生产和终霜同时存在地图与路线差异，当前证据不足以和社会轴一起改动。

## 用户确认的暂行测试口径

### 火盆集会

- 签署时的恐慌 -1 保持不变。
- 炉心运行且供暖完整支付时，每日日结仍尝试结算恐慌 -1。
- 每日被动效果只在当日其他社会结算后的预计恐慌高于 10 时生效，并且最多降低到 10。
- 恐慌等于或低于 10 时，火盆集会不再降低，也绝不把恐慌抬高。
- 事件、路线主动行动和其他非火盆来源仍可把恐慌降低到 10 以下。

### 誓言路线

| 项目 | Patch 017 值 | Patch 018 暂行值 |
| --- | ---: | ---: |
| 悼亡钟声签署 | 信任 +1，恐慌 -1 | 信任 0，恐慌 -1 |
| 共食誓餐签署 | 信任 +1，恐慌 0 | 信任 0，恐慌 0 |
| 余烬名册签署 | 信任 +1，恐慌 0 | 信任 0，恐慌 0 |
| 留城誓约签署 | 信任 +1，恐慌 0 | 信任 0，恐慌 0 |
| 守炉宣誓 | 冷却 3 天，信任 +3，恐慌 -1 | 冷却 4 天，信任 +2，恐慌 -1 |
| 共食誓餐行动 | 冷却 4 天，信任 +2，恐慌 -3 | 冷却 5 天，信任 +1，恐慌 -2 |
| 终火誓约签署 | 信任 0，恐慌 +4 | 信任 0，恐慌 +8 |

守炉誓言签署、悼亡钟行动、留城劝诫及共食誓餐的熟食消耗公式保持不变。终火誓约仍只承接信任归零失败，不能免疫恐慌、人口、炉心、饥饿、寒冷、疾病或死亡失败。

## 实现

- `data/laws.json` 新增 `firepit_daily_panic_floor=10`，由严格配置读取器校验为 0～100 的整数；每日减压值仍必须为负数。机器炉律视图同时公开每日变化、下限、运行前提和 `TEST_NUMERIC` 身份。
- 社会日结先完成配给、工时、遗体压力、饥饿及旧城当日收口等全部同日信任/恐慌结算，再于独立 `APPLY_DAILY_SOCIAL_RELIEF` 阶段应用火盆集会下限；终霜每日记录已移入随后的 `CAPTURE_DAILY_RECORDS` 阶段，最后才进入 `CHECK_HARD_FAILS`。因此固定顺序为“旧城结算 → 火盆减压 → 终霜每日记录 → 硬失败检查”，没有调整既有系统安装顺序，也没有改变其他情绪来源的相对结算顺序。
- `data/oath_order.json` 只调整上表列出的誓言值。机器路线视图公开 `TEST_NUMERIC` 身份，所有规则和命令结果继续直接读取同一配置，不维护第二套隐藏数值。
- 没有新增存档字段或改变存档版本。严格校验仅额外兼容 Patch 017 已经写入的守炉宣誓 `使用日+3` 与共食誓餐 `使用日+4` 两种历史截止日，并原样保留；Patch 018 后新执行的行动仍分别写入 `使用日+4` 与 `使用日+5`，其他行动不接受旧差值。

## 测试

- 火盆集会在恐慌 12、11 时逐日降至 10，达到 10 后停止；恐慌已经为 8 时不降低也不抬高。
- 同日存在其他恐慌压力时，火盆集会按汇总后的预计恐慌工作，但仍不越过下限。
- 完整 `GameSession` 回归覆盖日初恐慌 9、当日饥饿恐慌 +5，确认饥饿先结算到 14、火盆随后减至 13。
- 全真实系统 D48 日结回归覆盖旧城 `partial_exodus` 恐慌 +5，确认旧城先把恐慌从 9 结算到 14、火盆随后减至 13，并且火盆日志早于硬失败检查。
- 全真实系统 D49 日结回归覆盖日初恐慌 80，确认火盆先减至 79、终霜随后记录 `panic_crisis=false`，且记录日志早于硬失败检查。
- 非法下限和非负每日减压值会被配置加载拒绝。
- 机器路线视图逐项暴露本轮暂行值；守炉宣誓正式执行按 +2/-1 结算，并写入 4 天冷却。
- `GameSession.load` 回归分别覆盖 Patch 017 守炉宣誓与共食誓餐的旧冷却截止日，加载后历史值不被追溯改写。
