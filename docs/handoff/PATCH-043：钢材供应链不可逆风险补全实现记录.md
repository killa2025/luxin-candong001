# Patch 043：钢材供应链不可逆风险补全实现记录

## 1. 来源与结论

Patch 042 合并后的第三十九次纯黑盒验收确认木材风险主路径、字段语义、事务与确定性均通过，但发现既有 `technology.steel_supply_irreversibly_locked` 只判断能否支付钢材筛选的 5 钢，没有计入研究完成后建造首座小型采钢机所需的 25 钢。测试局在地表钢耗尽、尚无采钢机且当前钢材为 25 或 20 时仍返回空风险；虽然这不是 Patch 042 改出的回归，却是已经可严格证明的完整供应链缺口。

## 2. 正式判定

只有当前不存在任何小型采钢机时才评估钢材链：

1. 钢材筛选尚未付款时，计入其钢材成本；研究进行中或已经完成时，该成本为 0；取消研究不退款后，科技重新可研究，因此重新计入研究成本；
2. 始终计入首座小型采钢机的钢材成本；
3. 继续用 Patch 015 的 `surface_resource_recoverable_before_final_frost` 计算当前派员在 D49 前可采的地表钢，不改用 Patch 042 的木材未来满容量上界；
4. `当前钢材 + 可采地表钢 < 剩余研究钢材成本 + 首座采钢机钢材成本` 时返回强警告；恰好能够支付时不报警；
5. 已经存在小型采钢机时供应链已经建立，不再报警。

## 3. 机器字段

既有警告 ID、等级及原字段保持可识别，并补充：

- `required_building_type = small_steel_miner`；
- `technology_cost_paid`；
- `remaining_technology_steel_cost`；
- `small_steel_miner_steel_cost`；
- `small_steel_miner_unlocked`；
- `small_steel_miner_exists`。

`required_steel` 与 `steel_shortfall` 现在表示完整剩余接线成本及其缺口。科技视图和日结预览返回同一结构化事实，预览不修改状态。

## 4. 测试边界

覆盖研究未付款时 30 钢恰好可接线、研究已付款时 25 钢恰好可建、取消研究不退款后的 25/20 钢黑盒复现、研究完成但 24 钢不足、已有采钢机、D48 当前派员恰好补足、D49 停工排除地表余量，以及正式日结强警告不推进状态。

## 5. 越界自检

本 Patch 不修改钢材筛选或小型采钢机成本，不增加资源、不改变研究取消损失、正式地表产量、派员、D49 停工、地图、平衡、存档版本或随机流。警告只报告可证明事实，不推荐研究或建造行动。

不开始 Patch 044、D56、AI 策略或图形 UI。
