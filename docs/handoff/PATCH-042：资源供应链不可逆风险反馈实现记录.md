# Patch 042：资源供应链不可逆风险反馈实现记录

## 1. 来源与范围

第二十二次黑盒局曾因建造顺序耗尽木材，导致再也无法支付伐木场成本。Patch 041 合并后的 PENDING 盘点确认：钢材链已有保守的不可逆缺口视图和强警告，木材链只有 D49 终霜准备时才记录 `wood_supply_locked`，玩家在此前无法从正式机器接口获知已经不可恢复。

本 Patch 只补可由当前配置与状态严格证明的风险事实。不修改资源、成本、研究、产量、建筑、地图、事件、终霜、终局或任何平衡值，也不提供行动推荐。

## 2. 正式木材来源审计

当前运行机制中的木材来源只有：

- 开局及当前库存；
- D49 前仍可采集的地表木材；
- 已经建成的伐木场。

事件与固定增员不增加木材，旧城结算只可能扣除资源，`woodfuel` 只消耗木材。未封存的新资源来源不得被实现侧假设存在。

## 3. 严格锁死条件

`technology.wood_supply_irreversibly_locked` 仅在以下条件同时成立时出现：

1. 当前没有任何伐木场；
2. 木材加工 I 尚未完成或开始时，计入其尚未支付的木材成本；已经完成或正在研究时，该成本按 0 计算；
3. 始终计入新建一座伐木场的木材成本；
4. `当前木材 + D49 前最多可采地表木材 < 尚未支付的研究成本 + 一座伐木场成本`。

比较使用整数和严格小于。恰好能够支付时不报警。当日可采上界按现有工人与工程师在所有木材地表点之间的最佳合法重派计算，并扣除当日加班目标建筑中无法解除的工人与工程师。后续可采日的每日上界继续受当前成人总数与各地表点容量限制，不假设无限人力满产。多日合计仍取偏保守的可采上界：只有连上界都无法填平缺口才发出强警告。D49～D55 的地表资源点已经正式停工，即使状态中仍有地表余量，也不得计入可采木材。已有伐木场时供应链已建立，不因缺少派员、温度或终霜临时停工误报为不可逆资源锁死。既有钢材风险继续使用 Patch 015 的当前派员口径，不使用本段木材上界算法。

## 4. 机器接口

科技视图中 `tech_wood_processing_1.irreversible_resource_lock` 返回与日结强警告相同的结构化事实：

- 所需科技与建筑类型；
- 研究成本是否已经支付；
- 剩余研究木材成本与伐木场木材成本；
- 当前木材、地表剩余木材、D49 前可采木材；
- 可恢复木材总量与精确缺口；
- 当前不存在伐木场。

日结预览使用 `B_STRONG` 警告 `technology.wood_supply_irreversibly_locked`。它不阻止日结、不生成确认外的新协议，也不修改状态。既有 `technology.steel_supply_irreversibly_locked` 及其字段保持不变；两种警告可在各自条件成立时同时出现。

## 5. 测试

覆盖：

- 研究未支付时计算研究加伐木场的完整剩余成本；
- 研究已经开始时不重复计算已支付成本；
- 恰好能够通过当前库存与未来地表采集支付时不报警；
- 已有伐木场时不报警；
- D48 木材当前未派员但仍可合法重派采齐缺口时不误报；加班锁定全部成人时则不把他们冒充为可重派人力；
- D49 起地表余量不计入可采资源；
- 正式日结预览返回强警告且不推进状态；
- 既有钢材 D48 当前派员风险合同与原测试完整保留。

## 6. 越界自检

本 Patch 不新增救济资源、不退还错误投入、不降低建筑或科技成本、不改变地表资源量、生产速度、D49 停工、终局门槛或结局标签。警告只陈述已经成立的不可逆资源缺口，不告诉 AI 应当研究、建造或保留什么。

不提升存档版本，不开始 Patch 043、D56、AI 策略或图形 UI。

完成时实际结果：521 项 unittest 全部通过；9 份 JSON 配置校验、`compileall` 与 `git diff --check` 全部通过。

## 7. Draft PR 复审修正

第一轮复审确认木材原实现把“当前派员”误当成“当日最多可采”，会在 D48 尚能调入闲置或其他岗位人员时过早发出木材强警告。随后修正误将共用计算改动同时扩展到了钢材，并漏掉加班岗位的无法解除锁定。

第二轮复审后改为两条明确分离的合同：

- 钢材完整恢复 Patch 015 的当前派员算法和原回归测试；
- 木材使用独立的保守上界算法。当日枚举同类地表点的人员分配，但先扣除加班目标中正式命令无法解除的工人和工程师；后续日按成人总数与地表点容量计算每日上界，不再假设无限人力满产。

`docs/PENDING.md` 中仍称“钢材不可逆提示”待实现的旧句已删除；该文档修正保留。

第二轮修正完成时实际结果：522 项 unittest 全部通过；9 份 JSON 配置校验、`compileall` 与 `git diff --check` 全部通过。
