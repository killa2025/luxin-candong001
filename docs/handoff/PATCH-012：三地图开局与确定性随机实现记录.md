# PATCH-012：三地图开局与确定性随机实现记录

## 一、目标

补回 A008-2 已封存、但此前代码 Patch 003～011 未接入的三地图开局：

- 锈骨冻原：1 个大型煤矿点、2 个大型钢铁矿点，偏难；
- 黑烬洼地：2 个大型煤矿点、1 个大型钢铁矿点，标准；
- 双源裂谷：2 个大型煤矿点、2 个大型钢铁矿点，偏易；
- 新局支持随机地图和明确自选地图；
- 随机地图使用统一、可保存、可复现的 `DeterministicRandom`。

本 Patch 不实现大型矿机，因为其完整成本、岗位、产出与科技接线仍在 `docs/PENDING.md`。

## 二、资料边界与覆盖关系

地图差异只允许来自大型煤矿点和大型钢铁矿点。三张地图继续共享：

- 固定天气；
- 开局人口和全部开局资源；
- 4 个小型煤堆、5 个小型木材堆、3 个小型钢铁堆；
- 开局 1 个可用猎区、总计 2 个猎区；
- 2 个森林区；
- 生存、疾病、供暖、事件和终霜规则。

A008-2 旧文中的“第二猎区开启方式未封存”已被更高优先级的用户确认总收口覆盖。当前代码继续保持“第一座狩猎小屋成功建成后自动开放第二猎区”，不在本 Patch 倒退或重写。

## 三、运行配置

新增 `data/maps.json`，状态为 `FINAL`：

- 三个稳定内部 key：
  - `rustbone_tundra`
  - `black_ash_lowland`
  - `twin_source_rift`
- 随机整数权重按封存建议使用 33 / 34 / 33；
- `shared` 保存三图必须一致的小型资源点、猎区和森林数量；
- `templates` 只保存名称、难度与大型煤钢矿点数量；
- `legacy_default_map_key` 仅用于旧存档的确定性迁移，不是第三种玩家开局模式。

配置加载会严格拒绝：

- 非 `FINAL` 状态，以及任何偏离已封存名称、难度、共享数量、矿点数量、33/34/33 权重或旧档默认黑烬洼地的值；
- 缺失或额外地图；
- 权重未覆盖三图或总和不是 100；
- 非正整数资源点；
- 初始猎区超过总猎区；
- 地图共享数量与 `buildings.json` 的资源锚点不一致。

`manifest.json` 已登记 `maps.json`；配置树现校验 9 份 JSON 文件。

## 四、开局选择与随机性

Python 会话：

```python
GameSession.new(
    config_dir="data",
    save_path="save.json",
    seed=2025,
    map_mode="random",
)
```

自选：

```python
GameSession.new(
    config_dir="data",
    save_path="save.json",
    seed=2025,
    map_mode="manual",
    map_key="black_ash_lowland",
)
```

规则：

- `random` 禁止同时指定 `map_key`；
- `manual` 必须指定已登记的 `map_key`；
- 随机模式按“锈骨冻原 → 黑烬洼地 → 双源裂谷”的固定顺序和配置权重从统一随机流抽取，保存抽取后的随机状态，不依赖 JSON 对象字段顺序；
- 自选模式不消耗随机数；
- 同一初始种子和相同开局参数产生相同地图、随机状态和回放初态；
- 不为随机到的偏难图增加任何隐藏补偿。

CLI：

```text
python -m furnace_winter play save.json --seed 2025 --map-mode random
python -m furnace_winter play save.json --seed 2025 --map-mode manual --map-key rustbone_tundra
```

地图参数只在建立新存档时生效；读取已有存档始终使用存档中的地图。

## 五、状态、观察与回放

新增 `MapState`，保存：

- 地图 key、中文名、难度与选择模式；
- 三类小型资源点数量；
- 初始/总猎区和森林区数量；
- 大型煤矿点和大型钢铁矿点数量。

`GameSession.status()` 与完整 `Observation.map_view` 返回当前地图、资源点摘要、可用/总猎区、森林区和大型矿点。`rules_view("maps")` 返回已验证的原始地图配置。

回放初态保存完整 `MapState` 和抽取后的统一随机状态。随机地图不是回放时重新抽取，因此不会因进程或对话变化漂移。

## 六、存档 v13

存档版本由 v12 升至 v13。

v12 及更早的旧局没有地图历史，无法证明当时随机到了哪张图。迁移采用明确隔离的技术兼容口径：

- 迁移为标准图 `black_ash_lowland`；
- `selection_mode` 记为 `legacy_default`；
- 不消费、倒推或伪造随机抽取；
- 不修改旧局人口、资源、天气、建筑、事件或终局状态；
- 旧版本若夹带非默认地图字段，严格拒绝。

配置感知校验拒绝地图 key、名称、难度、矿点数量、共享资源点数量、随机抽取结果或资源锚点不一致的存档。
